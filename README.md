# student-expense-tracker
A simple console-based C++ program to track daily expenses as a student.

## Features
- Add Expense
- View All Expenses
- Search Expense
- Calculate Total Spending
- Show Category-wise Spending
- Delete Expense

## What I used
- C++ (structs, classes, file handling, STL containers like vector and map)

## What I learned
This was a mini project to practice C++ fundamentals — especially file handling (saving/loading data) and organizing code using classes.
